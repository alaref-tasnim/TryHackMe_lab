* sandbox > An isolated environment for safely testing software without affecting the main system.
* MITRE ATT&CK Framework > is basically a map of how hackers attack systems, target: Operating systems, cloud, endpoints, IT/OT networks
* ATLAS framework (Adversarial Threat Landscape for Artificial-Intelligence Systems) > target: Machine learning models, training pipelines, AI agents
* Microsoft Defender of Endpoint > Defender for Endpoint is behavioral security inside the device like a notebook, phone, etc.. (stopping malicious software from running once it is already on the machine).
*  PII > Personally Identifiable Information is any representation of data that can be used to identify an individual directly.
*  Pre-trained model: An AI model that has been trained on a large, general dataset to learn broad patterns, knowledge, and capabilities before being adapted for a specific task.
* Fine-tuned model: A pre-trained model that is further trained on a smaller, task- or domain-specific dataset to adapt its behaviour, knowledge, or performance to a particular purpose.
