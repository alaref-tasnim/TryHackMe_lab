* trust boundary:  is where data moves from one security context to another, and every one is a potential attack surface
* OWASP: The Open Web Application Security Project is a nonprofit foundation focused on understanding web technologies and exploitations and provides resources and tools designed to improve the security of software applications.
* (NIST): National Institute of Standards and Technology. This organisation develops frameworks and policies for information security that is used all throughout the industry.
* Prompt Construction: combines the system prompt, user query, and retrieved context into the final promot sent to the model 
* MLSecOps is the practice of integrating security throughout the machine learning lifecycle, from development and testing through deployment and live operations.
* Data Integrity means ensuring that data is accurate, complete, and remains uncorrupted and unaltered by unauthorized parties throughout its entire lifecycle.

STRIDE
* spoofing: Pretsending to be someone or something else to gain unauthorized access (e.g., stealing passwords or deepfake)
* Tampering: Unauthorized "modification" of data or code in transit, at rest, or during processing.
* Repudiation: A user denying that they performed an action or transaction because the system lacks proof or audit logs
* information disclosure كشف المعلومات / التسريب: "Exposing sensitive" or private data to unauthorized individuals.
* Denail of service: Disrupting or crashing a system or network so legitimate users cannot access it.
* Elevation of privilege رفع الصلاحيات: Gaining higher levels of access or permissions than authorized

* MITRE ATLAS: is a free, real-world knowledge base that tracks how attackers target and exploit AI and machine learning systems.
